ECEP EMBEDDED COURSE - FILE ORGANIZATION
========================================

This folder follows the 7 modules in the Emertxe ECEP syllabus.

Each module contains three categories:
1. 01_Templates  - Five numbered template folders (Template_01 to Template_05)
2. 02_Classworks - In-class programs, notes, and practical work
3. 03_Assignments - Assignments and their solutions/submissions

Suggested naming convention:
Templates:   TPL_001_TopicName
Classworks:  CW_001_TopicName
Assignments: ASG_001_TopicName

Keep source files, screenshots, PDFs, and related resources inside the relevant topic folder.
